# Chattygraph

AI-powered infographic and data visualization generator built with Next.js, Anthropic Claude, and Drizzle.

**Live:** https://chattygraph.vercel.app

## Stack

- TypeScript
- Next.js
- React
- Drizzle ORM
- Neon Postgres
- Clerk auth
- oRPC
- Tailwind
- shadcn/ui
- Vercel AI SDK

## Run

```bash
bun install
bun run dev
```
