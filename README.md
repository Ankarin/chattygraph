# chattygraph

Chattygraph — AI chat app with shareable conversation graphs (Next.js + Anthropic + Clerk + Drizzle).

**Live:** https://chattygraph.vercel.app

## Stack

- TypeScript
- Next.js
- React
- Drizzle ORM
- Neon Postgres
- Clerk auth
- oRPC
- Tanstack Query
- Tailwind
- shadcn/ui
- Vercel AI SDK

## Run

```bash
bun install
bun run dev
```
